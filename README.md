# PEARL Robot Hub Wireframe

A plain version of the PEARL Robot Hub frontend, without design and without functions.

Team: Haitam Bourahda (project lead), Mara Henkel, Emir Zeyrek, Tom Kaufmann, Niklas Orlov

Team supervisor: Julius Wahl

The full application is in [zeyrekemir/TPSE-Gruppe](https://github.com/zeyrekemir/TPSE-Gruppe).

## How to run

The wireframe is a single file, `index.html`. Nothing needs to be installed.

**Without a terminal:** download the repository (green *Code* button, then *Download ZIP*), unzip it and double click `index.html`. It opens in your default browser.

**With a terminal:** run these commands one after another.

Windows (PowerShell):

```bash
git clone https://github.com/zeyrekemir/PEARL-Robot-Hub-Wireframe.git
```

```bash
cd PEARL-Robot-Hub-Wireframe
```

```bash
start .\index.html
```

macOS:

```bash
git clone https://github.com/zeyrekemir/PEARL-Robot-Hub-Wireframe.git
cd PEARL-Robot-Hub-Wireframe
open index.html
```

Linux:

```bash
git clone https://github.com/zeyrekemir/PEARL-Robot-Hub-Wireframe.git
cd PEARL-Robot-Hub-Wireframe
xdg-open index.html
```

## How to use it

The buttons at the top switch between the pages: Sign in, Robots, Robot page, Calendar, Maintenance, Experiments, Statistics, Users and Legal. Nothing else on the page can be clicked.
